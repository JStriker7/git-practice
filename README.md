# git-practice

《开源软件开发与技术》课程 Assignment2 的个人 Git 练习仓库，用于练习分支、提交、Pull Request 以及合并冲突处理。

## 仓库内容

- `README.md`：仓库说明与练习流程。
- `practice.md`：用于分支修改和合并冲突练习的文本文件。

## 练习流程

1. 从 `main` 创建功能分支，完成修改并提交。
2. 通过 Pull Request 将功能分支合并回 `main`。
3. 与同学协作，在 `practice.md` 的同一行上制造并解决一次真实的合并冲突。

## 说明

本仓库仅用于课程 Git 练习，不包含课程项目代码，也不作为个人课程项目仓库。
